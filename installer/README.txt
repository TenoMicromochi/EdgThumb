EdgThumb 1.0.0

EDGE2 (.edg) Thumbnail Provider for Windows Explorer
Windows Explorer 用 EDGE2 (.edg) サムネイル表示拡張

----------------------------------------
[English]
----------------------------------------
EdgThumb shows thumbnails of EDGE2 (.edg) files in Windows Explorer.
It shows the page that is open in EDGE2, composed the way EDGE2 shows it.
The background colour is transparent.

- Unofficial. Not affiliated with Takabo Soft, the author of EDGE2.
- Windows 10/11 x64 only. Not supported on ARM64 Windows.
- EDGE2 files only (1/4/8/15/16/24 bit). EDGE1 files are not supported.
- Pixel art is enlarged or reduced by whole-number steps only, never smoothed.
- EdgThumb.dll is not code-signed. Windows may warn about it.

If thumbnails do not appear or are out of date, restart Explorer, or clear the
thumbnail cache (see the project page).

To uninstall, use "Apps > Installed apps" in Windows Settings.

----------------------------------------
[日本語]
----------------------------------------
EdgThumb は、EDGE2 の .edg ファイルのサムネイルをエクスプローラーに表示します。
EDGE2 で開いているページを、EDGE2 上の見え方のまま合成して表示します。
背景色は透明です。

- 非公式ツールです。EDGE2 の作者 Takabo Soft とは無関係です。
- Windows 10/11 の x64 のみ対応です。ARM64 版 Windows は非対応です。
- EDGE2 形式（1/4/8/15/16/24bit）のみ対応です。EDGE1 形式は非対応です。
- ドット絵は整数倍でのみ拡大縮小し、補間（ぼかし）をかけません。
- EdgThumb.dll にはコード署名がありません。Windows が警告を出すことがあります。

サムネイルが出ない、または古いままのときは、エクスプローラーを再起動するか、
サムネイルキャッシュを消してください（プロジェクトのページを参照）。

アンインストールは、Windows の設定「アプリ > インストールされているアプリ」から行います。
